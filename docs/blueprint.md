# **App Name**: DuoFit

## Core Features:

- Authentication: User authentication via email and Google Sign-In.
- Goal Selection: Set fitness goals (lose weight, gain mass).
- Workout Plan Selection: Browse recommended workout plans based on goals and equipment availability.
- Workout Tracking: Mark workouts as completed.
- Workout Calendar: View a calendar showing completed workouts.
- Progress Chart: Log and track weight and BMI over time, presented in chart form.
- Home Screen Dashboard: Home screen display of today's workout, current progress stats, and completion button.

## Style Guidelines:

- Primary color: A vibrant magenta (#D633FF) to evoke energy and determination. 
- Background color: A light lavender (#F0E6FF) provides a clean and modern feel. 
- Accent color: A rich violet (#7A00B8) highlights key actions and important information.
- Clean, sans-serif fonts optimized for mobile readability. 
- Simple, consistent icons representing different workout types and tracking metrics.
- Mobile-first design with clear information hierarchy and easily accessible controls.
- Subtle animations and transitions for user feedback and enhanced engagement.
